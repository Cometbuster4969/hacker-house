## LinkedIn

🕵️‍♂️ Just built an Agentic Fraud Investigation Agent powered by TigerGraph for the Hacker House Goa 2026 hackathon!

The challenge: Build an AI agent that investigates fraud alerts, creates and progresses cases, and recommends next-best actions — under uncertainty.

Our solution:
🔹 8-step investigation cycle from trigger to case memory
🔹 TigerGraph knowledge graph with 8 vertex types and 20 edge types
🔹 15 MCP tools exposing graph operations to the agent
🔹 Policy engine enforcing 10 fraud rules (R1-R10) with approval routing
🔹 Pattern detection for card testing, CNP fraud, account takeover, and more
🔹 Case memory through graph writes — each investigation becomes evidence for the next
🔹 Web dashboard for analysts to review cases, evidence, and recommendations

Key learnings:
1️⃣ Graph-native investigation reveals patterns invisible to row-based analysis
2️⃣ Calibration matters more than raw accuracy — half the cases are legitimate
3️⃣ Case memory is a multiplier for investigation quality
4️⃣ Policy compliance requires careful engineering, not just good intentions

The dataset: 590K transactions, 144K identity records, 5,565 closed historical cases, and 20 benchmark cases from the IEEE-CIS Fraud Detection dataset.

TigerGraph makes it natural to trace money through shared devices, billing regions, and connected cards. The graph structure maps perfectly to how fraud actually works.
